# Ricalca

Web app per ricalcare una foto: la carichi, la regoli (posizione, zoom, rotazione, opacità, contrasto) e
blocchi il tocco con un lucchetto per disegnare senza spostarla. Per sbloccare si tiene premuto il lucchetto.

Una pagina sola (`index.html`), nessun backend, nessuna dipendenza. Installabile come app dalla schermata Home.
